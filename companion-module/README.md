# Stage Timer Companion module

Bitfocus Companion connection module for the Stage Timer app in the parent directory.

```sh
corepack yarn install
corepack yarn package
```

The build creates `companion-module-juliuskolosnjaji-stage-timer-1.0.0.tgz`. In Companion, open **Modules**, choose **Import module package**, import that file, and add a **Stage Timer** connection. See `companion/HELP.md` for configuration and available presets.
